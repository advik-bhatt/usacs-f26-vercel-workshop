# 08 · AI SDK + AI Gateway ★

**Demo page:** `/demos/ai` · **Time:** ~15 min


- **[AI SDK](https://ai-sdk.dev)** (`ai`, `@ai-sdk/react`): one TypeScript API
  for streaming text, tools, structured output and chat UIs, across all providers.
- **[AI Gateway](https://vercel.com/docs/ai-gateway)**: one endpoint and one
  bill for hundreds of models (OpenAI, Anthropic, Google, xAI, Meta…), with
  fallbacks, usage tracking and no provider keys to manage.

In AI SDK v7, a plain string like `"openai/gpt-5-mini"` routes through the AI
Gateway automatically. Switching models means changing one string.

## 1. Authenticate

Pick **one**:

- **OIDC (no key):** on Vercel it just works. Locally, `npx vercel env pull` gives you
  `VERCEL_OIDC_TOKEN` (valid about 12h).
- **API key:** dashboard → **AI Gateway** → **API Keys** → create one, then add
  it as `AI_GATEWAY_API_KEY` in your project's env vars.

The model is a plain string in the route (`openai/gpt-5-mini`). Swap it for any
"provider/model" id from the AI Gateway model list, deploy, and ask again. For a
long-lived key: `vercel ai-gateway api-keys create`.

## 2. The chat endpoint

`src/app/api/chat/route.ts` (open `/chat` to use it):

```ts
import {
  streamText, convertToModelMessages, createUIMessageStreamResponse,
  toUIMessageStream, tool, isStepCount, type UIMessage,
} from "ai";
import { z } from "zod";

export const maxDuration = 60;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: "openai/gpt-5-mini",                         // ← any provider/model
    instructions: "You are a friendly TA. Keep answers short.",
    messages: await convertToModelMessages(messages),   // async in v7
    tools: {
      getTime: tool({
        description: "Get the current time in an IANA timezone",
        inputSchema: z.object({ timeZone: z.string() }),
        execute: async ({ timeZone }) => ({
          time: new Date().toLocaleString("en-US", { timeZone }),
        }),
      }),
    },
    stopWhen: isStepCount(5),   // allow: call tool → read result → answer
  });

  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

## 3. The chat UI

`src/app/chat/chat.tsx`:

```tsx
"use client";
import { useChat } from "@ai-sdk/react";
import { useState } from "react";

export function Chat() {
  const [input, setInput] = useState("");
  const { messages, sendMessage, status } = useChat(); // POSTs to /api/chat by default

  return (
    <>
      {messages.map((m) => (
        <div key={m.id}>
          {m.role}:{" "}
          {m.parts.map((p, i) => (p.type === "text" ? <span key={i}>{p.text}</span> : null))}
        </div>
      ))}
      <form onSubmit={(e) => { e.preventDefault(); sendMessage({ text: input }); setInput(""); }}>
        <input value={input} onChange={(e) => setInput(e.target.value)} />
        <button disabled={status !== "ready"}>Send</button>
      </form>
    </>
  );
}
```

Ask *"what time is it in Tokyo?"* and watch the `getTime` tool call appear.

## 4. Structured output

`src/app/api/ai/plan/route.ts`:

```ts
import { generateText, Output } from "ai";
import { z } from "zod";

const { output } = await generateText({
  model: "openai/gpt-5-mini",
  output: Output.object({
    schema: z.object({
      topic: z.string(),
      steps: z.array(z.object({ title: z.string(), minutes: z.number() })),
    }),
  }),
  prompt: "Make a short study plan for learning Next.js",
});
// output is fully typed: output.steps[0].title
```

> Coming from older tutorials? In v7, `generateObject` is deprecated (use
> `output: Output.object`), `system` → `instructions`, `stepCountIs` →
> `isStepCount`, `toUIMessageStreamResponse()` → `createUIMessageStreamResponse`,
> and `useChat` no longer manages `input` for you.
